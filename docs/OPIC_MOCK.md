# 시나리오와 OPIc 모의시험

## 연습 은행

OPIc 28개, 일상 회화 14개. `content/scenarios.json`이 콘텐츠 원본이다. OPIc은 자기소개, 집, 여행, 공원, 음악, 운동, 기술, 예약 롤플레이를 포함한다. 묘사·일상 습관·과거 경험·비교·의견·질문하기·문제 해결 유형을 제공한다. 일상 회화는 식당·카페·길 찾기·호텔·쇼핑·직장·예약·약속·분실물·이웃과의 부탁으로 구성한다. 주제와 유형으로 필터링할 수 있다.

## 모의시험 흐름

OPIc 탭 → 모의시험 준비 → 관심 주제 2개와 12/15문항 선택 → 마이크 허용·질문 음성 준비 → 40분 시험 → 문항별 복습.

- 12문항: 자기소개 1 + 선택 주제 2세트 각 3 + 다른 주제 2 + 롤플레이 3.
- 15문항: 자기소개 1 + 선택 주제 2세트 각 3 + 다른 주제 3 + 롤플레이 3 + 비교·의견 2.
- 7문항 후 중간 선택. 15문항에서 마지막 두 질문을 쉬운 묘사·일상 질문 또는 더 도전적인 의견 질문으로 조정한다. 이미 답한 질문과 연결된 세트는 바꾸지 않는다. 12문항은 구성을 유지한다.
- 질문은 기기에 미리 내려받아 준비 시간이 시험 시간을 차감하지 않도록 한다. 중간 조정에서 새 음성이 필요할 때는 준비 시간도 타이머에 포함된다.
- 질문은 처음 한 번 자동 재생, 한 번 추가 듣기를 제공한다. 질문 텍스트는 기본 숨김이며 읽기 보조를 켤 수 있다. 음성 준비 실패 시 읽기 보조로도 시작할 수 있다.
- 전체 시간은 시작 시각으로 계산한다. 문항별 2분 제한을 두지 않는다. 앱을 나가도 40분은 계속 흐르고 녹음은 정지·저장한다. 강제 종료 중 녹음은 복구를 보장하지 않는다.
- 한 번 넘어간 문항은 시험 중 다시 녹음하지 않는다. 무응답은 확인 후 건너뛴다. 종료 후 듣기와 코칭이 가능하다.
- 종료 후 원하는 답변만 기존 비공개 업로드·전사·코칭 흐름으로 제출한다. 세션·업로드·전사 ID를 저장해 재시도 시 재사용한다. 미제출 녹음은 기기에 남고 새 시험 준비 시 삭제한다.
- 모의시험 녹음은 32 kbps mono AAC로 저장한다. 업로드 파일 최대 10 MB는 유지하며 길이 검증은 최대 40분으로 확장한다.

## 공식 시험과의 관계

SpeakLoop가 만든 학습용 문제·구성이다. 공식 문제를 복제하거나 공인 등급을 산출하지 않는다. 앱의 관심 주제 2개 선택, 12/15문항 구성, 중간 선택과 음성 재생 제한은 앱의 연습 규칙이며 공식 시험의 모든 절차를 그대로 구현했다는 뜻은 아니다.

## 서버·저장

`POST /v1/scenarios/{id}/audio`는 인증 후 활성 시나리오의 서버 원문만 합성한다. 질문 음성은 시나리오·버전·영어 기준별 캐시를 모든 사용자에게 재사용하며 서버 전용 테이블에서 관리한다. 생성 시도는 캐시당 최대 3회, 원자적 예약과 worker claim으로 중복 생성을 막는다. 반환 URL은 5분이며 시험 시작 전에 앱 파일로 내려받는다. 질문 음성에는 사용자 녹음이 포함되지 않는다.

모의시험 상태는 사용자 ID별 AsyncStorage 키로 분리하고 질문·답변은 앱 문서 폴더에 둔다. 로그인한 사용자의 시험만 복원한다. 다른 기기 동기화는 지원하지 않는다.

## 검증

API 테스트 32개, 모의시험 계획 테스트 5개. 관심 주제의 모든 두 개 조합에서 12/15문항 수·고유성, 세트 연결, 중간 조정, 앱 밖에서도 계속되는 타이머를 확인한다. 실제 DB에서는 활성 시나리오 수, 클라이언트 권한 차단, 중복 예약의 시도 횟수 유지 확인 후 롤백했다.

Android 기기에서 음성 준비, 권한 요청, 실제 녹음·중단·복귀, 40분 종료, 결과 제출은 추가 확인이 필요하다. iOS는 추후 실기기 검증한다.
