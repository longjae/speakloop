# SpeakLoop · Tinkit Studio 디자인 시스템 v1

## 브랜드 방향

제공된 Tinkit Studio 이미지의 블랙 프레임, 실버 표면, 민트색 점을 기준으로 한다. 수달의 친근함은 둥근 카드와 짧고 부드러운 문장으로 표현한다. 원본 로고를 앱 아이콘으로 재사용하거나 수달 일러스트를 변형하지 않는다. SpeakLoop 이름과 민트색 점으로 제품과 스튜디오의 관계를 표현한다.

블랙 60% · 실버 30% · 민트 10%를 화면의 시각적 비중으로 사용한다. 픽셀 수를 강제로 맞추는 비율은 아니다. 블랙은 배경과 카드, 실버는 정보와 경계, 민트는 가장 중요한 행동·포커스·브랜드 포인트에 사용한다. 보조 버튼을 모두 민트로 칠하지 않는다.

## 색상

| 역할 | 값 | 사용 |
|---|---|---|
| Background | `#0C0E0F` | 화면·헤더 |
| Surface | `#171A1C` | 카드·입력창·상태 안내 |
| Elevated | `#222729` | 보조 버튼 |
| Border | `#3A4245` | 카드·입력창 경계 |
| Text | `#F0F2F2` | 제목·주요 정보 |
| Silver | `#B8C1C4` | 본문·보조 정보 |
| Muted | `#929DA1` | 라벨·입력 힌트 |
| Mint | `#00D2BC` | 주요 행동·포커스·로고 점 |
| On mint | `#062B26` | 민트 버튼의 글자 |
| Danger | `#FFA8A8` | 오류 설명 |

실버는 넓고 밝은 판보다 글자·아이콘·경계와 차콜 단계로 분산한다. 사진의 크림·갈색은 브랜드 일러스트에만 두고 기본 UI 팔레트로 확장하지 않는다. 오류는 색과 함께 문장으로 설명한다.

## 글자와 간격

- Android·iOS 기본 시스템 글꼴을 사용한다. 새 폰트 설치 없이 자동 업데이트에 적용한다.
- 페이지 제목 30/39, 카드 제목 21/29, 본문·버튼 16/25, 보조 라벨 12/18.
- 글자 확대를 허용하며 고정 높이로 문장을 자르지 않는다.
- 간격 단위: 4, 8, 12, 16, 24, 32, 48. 화면 좌우 24, 카드 안 24.
- 카드 모서리 20, 입력창·버튼 모서리 14. 그림자보다 표면 밝기와 경계로 구분한다.

## 공통 컴포넌트

- `Brand`: SpeakLoop 워드마크와 민트 점. 로그인에는 스튜디오 출처, 헤더에는 작은 워드마크.
- `Button`: primary(민트), secondary(차콜·실버), quiet(투명). 최소 높이 52, 비활성·눌림 상태, 접근성 역할·상태 제공.
- `TextInput`: 차콜 배경, 밝은 글자, 민트 커서·포커스 경계, 입력 목적 라벨.
- `Text`: 실버 본문을 기본으로 하고 제목·오류만 명시적으로 변경.
- `ui.card`: 시나리오·모드·결과를 같은 여백과 표면으로 표시.
- 상태 안내: 버튼 가까이에 처리 중·성공·실패를 문장으로 표시하고 화면 읽기에 알린다.

색상·간격·공통 스타일은 `apps/mobile/lib/theme.ts`, 컴포넌트는 `apps/mobile/components/ui.tsx`에서 관리한다. 새 화면은 개별 색상 문자열을 추가하기 전에 토큰을 사용한다.

## 화면과 S3 확장

로그인: 브랜드 → 한 문장 설명 → 입력 → 주요 로그인 → 보조 계정 작업.
홈: 인사 → 두 연습 모드 → 최근 기록. 시나리오: 질문·수준·목표 → 시작.
녹음: 질문 → 녹음·제출 → 처리 상태 → 원본 전사 → 인식 오류 수정.
S3 결과: 핵심 피드백 → 잘한 점 → 교정 1~3개 → 개선 예문·듣기 → 다시 말하기. 결과 카드가 늘어나도 민트는 주요 다음 행동에 집중한다. 점수나 성공을 색만으로 전달하지 않는다.

## 검증 범위

타입 검사, 토큰의 글자 대비 계산, Android 번들 내보내기를 확인한다. 현재 대비는 실버 본문/Surface 9.55:1, 보조 글자/Surface 6.29:1, 민트 버튼 글자 7.92:1이다. 실제 기기의 글자 확대·스크롤·키보드·포커스·터치 상태는 Android에서 확인한다. iOS 구현은 유지하고 실기기 검증은 추후 진행한다.
